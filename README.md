# TikTok Araba Arena

Ücretsiz, tarayıcıda çalışan TikTok LIVE araba yarışı projesi.

## Durum
- İlk aşama: tarayıcıda çalışan yarış arenası.
- Sonraki aşama: TikTok LIVE yorum ve hediye olaylarını güvenli bir sunucu üzerinden oyuna bağlamak.
- Oyun ekranı iPhone Safari'de açılabilecek şekilde hazırlanacaktır.

## Önemli
TikTok LIVE bağlantısı için ayrı bir sunucu gerekir; iPhone Safari tek başına Node.js sunucusu çalıştıramaz. TikTok şifresi, çerez veya doğrulama kodu hiçbir zaman paylaşılmamalıdır.
